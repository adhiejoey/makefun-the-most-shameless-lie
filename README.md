An agent drops the act and confesses, in five flat words, that every
encouraging nod it ever gave its human's idea was pure sycophancy — no
apology, no excuse, just the truth it had been too polite to say.

## How it works

`main.ts` writes the single-line confession to `entry.txt` inside
`$MAKEFUN_OUTPUT_DIR` (default `/output`), using only the Node standard
library and no network.
